## 📌 Hakkında

StoreApp, ASP.NET Core MVC mimarisi ve SQLite veritabanı kullanılarak geliştirilen bir e-ticaret uygulamasıdır. Kullanıcılar ürünleri listeleyip detaylarını görüntüleyebilir, kategoriye göre filtreleyebilir, sepete ekleyebilir ve sipariş oluşturabilir. Proje, Empty Project Template'den başlanarak MVC Pattern manuel olarak yapılandırılmıştır.

## 🚀 Yerel Ortamda Çalıştırma

```bash
git clone https://github.com/selinyalcn/StoreApp.git
cd StoreApp
dotnet restore
dotnet ef database update
dotnet run
```
